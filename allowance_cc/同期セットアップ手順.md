# 同期セットアップ手順(保護者向け)

おこづかいちょうのデータを Google スプレッドシートに自動保存する設定です。
**一度だけ、10分ほどの作業**が必要です。以降は記録するたびに自動で保存されます。

作業は**保護者のスマホ/PC**で行ってください(子どものiPadでは行いません)。

---

## 全体の流れ

```
① スプレッドシートを作る
② スクリプトを貼り付けて、合言葉を決める
③ ウェブアプリとして公開して、URLを取得する
④ アプリの保護者ページにURLと合言葉を入れる
```

---

## ① スプレッドシートを作る

1. ブラウザで https://sheets.new を開く(新しいスプレッドシートができます)
2. 左上のファイル名を「**おこづかいちょう データ**」など分かりやすい名前に変更する

> シートの中身は空のままで構いません。必要なシートはスクリプトが自動で作ります。

---

## ② スクリプトを貼り付けて、合言葉を決める

1. メニューの「**拡張機能**」→「**Apps Script**」をクリック
2. エディタが開いたら、最初から書かれているコード
   (`function myFunction() {}` など)を**すべて削除**する
3. このフォルダにある **`sync.gs`** の中身をすべてコピーして貼り付ける
4. 上から6行目あたりにある次の行を探す

   ```js
   var SECRET = 'kaeru-2026-himitsu';   // ←★ここを自分の合言葉に書き換える
   ```

5. `kaeru-2026-himitsu` の部分を、**自分で決めた合言葉**に書き換える
   - 例: `okozukai-yamada-4821`
   - 英数字とハイフンだけを使い、**推測されにくい文字列**にしてください
   - **この合言葉は手順④で使うので、控えておいてください**

6. 保存する(フロッピーディスクのアイコン、または `Ctrl/⌘ + S`)

---

## ③ ウェブアプリとして公開して、URLを取得する

1. 右上の「**デプロイ**」→「**新しいデプロイ**」をクリック
2. 左上の歯車アイコン ⚙ →「**ウェブアプリ**」を選ぶ
3. 次のように設定する

   | 項目 | 設定する値 |
   |---|---|
   | 説明 | (何でも可。例: v1) |
   | 次のユーザーとして実行 | **自分**(あなたのメールアドレス) |
   | アクセスできるユーザー | **全員** |

   > 「全員」にするのは、**子どものiPadからGoogleログインなしで書き込めるようにする**ためです。
   > 実際にシートを操作するのはあなたのアカウントなので、シートは非公開のままです。

4. 「**デプロイ**」をクリック
5. **初回のみ、承認を求められます**
   1. 「アクセスを承認」をクリック
   2. 自分のGoogleアカウントを選ぶ
   3. 「**このアプリは Google で確認されていません**」と警告が出る
      → 自分で作ったスクリプトなので問題ありません
      → 「**詳細**」→「**(プロジェクト名) に移動**」をクリック
   4. 「許可」をクリック
6. 表示された「**ウェブアプリ**」の URL をコピーする
   - `https://script.google.com/macros/s/AKfycb.../exec` という形です
   - **末尾が `/exec` であることを確認**してください(`/dev` ではありません)

---

## ④ アプリに設定する

1. 子どものiPadでおこづかいちょうを開く
2. 右上の「**👤 保護者**」→ 暗証番号を入力
3. 「**データの同期(Google スプレッドシート)**」の欄に入力する
   - 上の欄: 手順③でコピーした **URL**
   - 下の欄: 手順②で決めた **合言葉**
4. 「**接続テスト＆保存**」をタップ
5. 「接続してデータを送りました」と出れば完了です

> URLが長いので、メールやメモアプリで自分に送ってiPadで貼り付けると簡単です。

---

## 確認

スプレッドシートを開き直すと、次の3つのシートができています。

| シート名 | 内容 |
|---|---|
| **明細** | おさいふの収支(日付・カテゴリ・金額・メモ) |
| **ぎんこう** | 口座の預け入れ・引き出し・利息 |
| **設定** | 残高・年利・最終更新など |

`設定` シートの上部に「おさいふ残高」「ぎんこう残高」「合計」が出ているので、
**ここを見るだけで今の状況が分かります。**

## ⚠️ 大切な注意

### URLと合言葉は「パスワード」です
この2つを知っている人は誰でもデータを読み書きできます。
**人に教えたり、SNSに貼ったりしないでください。**

### URLは必ず控えておいてください
iPadのデータが消えた場合、**URLと合言葉を入れ直すことで復元できます**。
逆に言えば、これを忘れると復元できません。
パスワード管理アプリやメモに保存しておいてください。

> 保護者ページの「バックアップを保存」で作られる JSON ファイルにも
> URLと合言葉が入っています。このファイルを保管しておけば控えの代わりになります。

---

## こんなときは

| 症状 | 対処 |
|---|---|
| 「合言葉が違います」と出る | 手順②の `SECRET` と、④で入力した文字列が一致しているか確認。スクリプトを直したら**再デプロイ**が必要です |
| 「接続できません」と出る | URLの末尾が `/exec` か確認。「アクセスできるユーザー」が**全員**になっているか確認 |
| ホーム画面に「同期が7日以上できていません」と出た | 保護者ページを開き「今すぐ同期」を試す。だめなら上の2つを確認 |
| 「内容の食い違いがあります」と出た | 複数の端末から書き込まれた可能性があります。保護者ページで**どちらを残すか**選んでください |
| スクリプトを修正した | 「デプロイ」→「**デプロイを管理**」→ 鉛筆アイコン → バージョンを「新バージョン」にして更新。**URLは変わりません** |

---

## 仕組みについて(参考)

- データの本体は**これまでどおり iPad の中**にあります。スプレッドシートはその**写し**です
- そのため、**電波がなくても今までどおり記録できます**。通信できないときは端末にためておき、
  つながったときに自動で送ります
- 記録するたびに、5秒ほどまとめてから送信します
- 子どもがGoogleにログインする必要は一切ありません

詳しい設計は `設計_データ同期.md` を参照してください。
